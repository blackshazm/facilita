# Phase 5.1: Payment Escrow & Wallet Module - Plan

**Status:** Draft
**Phase:** 5.1
**Mode:** standard

## Phase Summary
Implement the financial backbone of FACILITA using a Modular Hexagonal architecture. This includes a double-entry Ledger system (Wallet), Pagar.me integration for Escrow (Auth/Capture), and automated tiered payout scheduling.

## 🔒 Security Threat Model
- **T-5.1-01: Double Spending / Race Conditions**: Wallet updates use Prisma transactions with optimistic/pessimistic locking.
- **T-5.1-02: Webhook Spoofing**: Validate Pagar.me signature (X-PagarMe-Signature).
- **T-5.1-03: Precision Loss**: Cents-only logic (BigInt) prevents decimal exploits.
