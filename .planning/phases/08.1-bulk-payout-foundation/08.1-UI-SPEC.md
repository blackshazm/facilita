# UI Design Contract: Phase 08.1 — Bulk Payout Foundation

## Visual Direction
- **Theme**: Dark Mode (Slate-950 / Emerald-500) - Matching the existing FACILITA Admin aesthetic.
- **Tone**: Professional, precise, and secure.

## Key Screens & Components

### 1. "Pagamentos Pendentes" Tab
- **Placement**: A new primary tab in the `/admin/payouts` view.
- **Layout**: Data table with multi-select capabilities.
- **Elements**:
    - Checkbox in the table header (Select All).
    - Checkboxes for each row.
    - Floating Action Bar or Header Action: "Processar Lote ([N])".

### 2. Bulk Action Modal (Confirmation)
- **Trigger**: Click "Processar Lote".
- **Content**: 
    - Summary of selected items: "Você selecionou [N] pagamentos totalizando **R$ [TOTAL]**."
    - Warnings: "Certifique-se de que o saldo no Pagar.me é suficiente."
    - Actions: "Cancelar" / "Confirmar e Processar".

### 3. Gateway Balance Widget
- **Placement**: Top right of the Payouts Dashboard or sticky sidebar.
- **Design**:
    - Value: Available balance in Pagar.me (Emerald text).
    - Subtext: "Sincronizado há [X] minutos".
    - Comparison: "Necessário para pendentes: R$ [TOTAL]".

## Interaction Patterns
- **Multi-select**: 
    - Shift-click support for range selection.
    - Clear visual indicator for selected rows (subtle background change to `emerald-500/10`).
- **Processing State**: 
    - Global progress bar or toast notification while the batch is being enqueued.
    - Real-time updates as BullMQ workers process the items (via Socket.io if available, or polling).

## Spacing & Typography
- **Typography**: Inter / Outfit (matching brand).
- **Table Spacing**: Comfortable padding (`px-8 py-6`) for high readability of bank data.

## Color Palette
- **Primary**: `emerald-500` (Actions, Success).
- **Secondary**: `slate-950` (Background), `slate-900` (Cards/Tables).
- **Status**: 
    - `amber-500`: Pending.
    - `rose-500`: Failed/Insufficient Balance.
