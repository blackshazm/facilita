## Wave 2: Business Logic & API

### [NEW] Use Cases
#### [NEW] [start-batch-payout.usecase.ts](file:///d:/Desktop/facilita/apps/api/src/modules/payments/application/start-batch-payout.usecase.ts)
- Receives `payoutIds` and `adminId`.
- Validates status of all payouts (must be `PENDING_APPROVAL`).
- Creates `PayoutBatch` record.
- Enqueues jobs in `BATCH_PAYOUT_QUEUE`.
- Updates payout statuses to `PROCESSING`.

#### [NEW] [get-batch-status.usecase.ts](file:///d:/Desktop/facilita/apps/api/src/modules/payments/application/get-batch-status.usecase.ts)
- Returns progress (processed/total) and status of a batch.

### [NEW] BullMQ Processor
#### [NEW] [batch-payout.processor.ts](file:///d:/Desktop/facilita/apps/api/src/modules/payments/infrastructure/queues/batch-payout.processor.ts)
- Extends `WorkerHost`.
- For each job:
    1. Check marketplace balance via `PayoutPort.getBalance`.
    2. If insufficient, mark batch as `FAILED_NO_FUNDS` and stop.
    3. Call `PayoutPort.transfer`.
    4. Update `PayoutBatch` progress and `Payout` status.
    5. Log to `FinancialAuditService`.
