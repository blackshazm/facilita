# Phase 7.1: Payout Automation & Ledger Hardening - Context

**Gathered:** 2026-05-06
**Status:** Ready for planning

<domain>
## Phase Boundary

This phase automates the financial payout lifecycle, moving money from the internal platform Wallet to the providers' bank accounts via Pagar.me V5. It includes bank data management, automated scheduling, and a self-healing reversal mechanism for failed transfers.

<decisions>
## Implementation Decisions

### Disparo do Payout (Transferência Bancária)
- **D-01:** O processamento de Payouts será **Agrupado (Batch)**.
- **D-02:** Um job diário (Cron) rodará na madrugada (ex: 02h) para processar todo o saldo disponível acumulado, facilitando a conciliação e reduzindo custos operacionais.

### Gestão e Privacidade dos Dados Bancários
- **D-03:** Os dados bancários (Agência/Conta) serão mantidos **Isolados no Módulo de Pagamentos**.
- **D-04:** Aplicação de criptografia em repouso para os campos sensíveis de conta bancária, seguindo o princípio de responsabilidade única e conformidade de segurança.

### Trava de Segurança (R$ 2.000+) e Notificações
- **D-05:** Implementação de uma **Fila de Aprovação Manual** para qualquer Payout unitário acima de R$ 2.000,00.
- **D-06:** O sistema enviará uma **Notificação Ativa** (E-mail/Dashboard Alert) para o administrador sempre que uma transferência entrar em espera para aprovação.
- **D-07:** Em caso de falha bancária, o estorno para a Wallet será acompanhado de uma **Push Notification** imediata para o prestador solicitando a revisão dos dados.

### the agent's Discretion
- Definição da tecnologia de criptografia (AES-256-GCM recomendada).
- Design exato da interface de "Payouts Falhos" no Admin Dashboard.

</decisions>

<specifics>
## Specific Ideas
- "Dinheiro na conta dele mais travado": Garantir que o saldo saia da Wallet apenas após a confirmação de sucesso do gateway ou fique em "Escrow" durante o processamento.
- Travas de segurança baseadas em valor para evitar grandes perdas em caso de comprometimento de conta.

</specifics>
