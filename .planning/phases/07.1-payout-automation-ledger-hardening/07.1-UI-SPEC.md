# UI-SPEC — Phase 7.1: Payout Automation (Dados Bancários Screen)
*Generated: 2026-05-06 | Status: APPROVED*

---

## 1. Scope

This spec governs the **"Dados Bancários"** screen in the FACILITA Provider App (Expo / React Native).
It also covers the **Payout Status Card** (new component in the provider home/wallet area).

**Screens in scope:**
- `BankDataScreen` — CRUD for bank account details
- `PayoutStatusCard` — Shows latest payout status in wallet view

**Out of scope:** Admin Backoffice UI for payout approval (separate phase).

## 4. Component Contracts

### 4.1 FormInput (reuse from RegisterScreen pattern)

```ts
interface FormInputProps {
  icon?: React.ReactNode;
  placeholder: string;
  value: string;
  onChangeText: (v: string) => void;
  keyboardType?: 'default' | 'numeric' | 'phone-pad';
  maxLength?: number;
  flex?: number; // for side-by-side layout (0–1)
}
```

**States:**
- Idle: border `#e2e8f0`, bg white
- Focused: border `#059669` (2px), bg white
- Filled: border `#059669` (1px)
- Error: border `#ef4444`, helper text below in `#ef4444`

**Dimensions:** height 56px, paddingH 12px, borderRadius 12px

### 4.2 AccountTypeToggle

Two pill buttons side-by-side. Selected: bg `#059669`, text white. Unselected: bg `#f0fdf4`, border `#059669`, text `#059669`.

```
[ Corrente ]  [ Poupança ]
```

### 4.3 SecurityBadge (24h Lock Warning)

Only shown if `bankDataUpdatedAt` is set AND less than 24h ago.

```
┌──────────────────────────────────────────────────────┐
│  ⚠️  Saque bloqueado por segurança                   │
│     Seus dados foram alterados. O próximo saque      │
│     será processado em {horasRestantes}h.             │
└──────────────────────────────────────────────────────┘
```

- Border: `#f59e0b` (1px)
- Bg: `#fffbeb`
- Icon: `AlertTriangle` (lucide-react-native), color `#f59e0b`
- Text: 14px, color `#92400e`

## 5. Interaction & Motion Contracts

| Interaction | Behavior |
|---|---|
| Save button tap | Show `ActivityIndicator` inside button (same pattern as RegisterScreen) |
| Save success | `Alert.alert('Dados salvos!', 'Seu próximo saque será processado automaticamente.')` |
| Save with 24h lock | Show `SecurityBadge` immediately above the button |
| Payout FAILED notification | Toast from top: `⚠️ Saque Falhou — Valor devolvido à Wallet` |
| Field validation error | Red border + helper text below field |
| Back navigation | Standard `navigation.goBack()`, no transition override needed |

### Loading State

Button transitions: `[Save →]` → `[⌀ Salvando...]` → `[✓ Salvo!]` (1.5s) → back to normal.

## 7. Accessibility

- All inputs must have `accessibilityLabel` matching the placeholder text.
- `SecurityBadge` must have `accessibilityRole="alert"`.
- CTA button: `accessibilityState={{ disabled, busy: loading }}`.
- Minimum tap target: 44x44px (enforced via minHeight 56px on inputs).

## 8. API Contract

**Endpoint:** `PUT /payments/bank-data`
**Guard:** JwtAuthGuard (token in Authorization header)
**Payload:**
```json
{
  "bankCode": "341",
  "bankBranch": "0001",
  "bankBranchDigit": "0",
  "bankAccount": "12345",
  "bankAccountDigit": "6",
  "bankAccountType": "CHECKING"
}
```
**Success response:** `{ "message": "Bank data updated successfully. 24h payout lock active." }`

**GET /payments/bank-data** — Returns masked account (last 4 digits) + `bankDataUpdatedAt`.
