# Validation Strategy — Phase 6.1: Operational Analytics & BI

## Overview
This document defines the validation criteria for the Operational Analytics & BI module, ensuring data integrity between transactional systems and reporting dashboards.

## Validation Criteria

### 1. Data Integrity (DI)
- **DI-01**: The sum of `gmv` in `DailyMetric` for a specific day MUST match the sum of successful `Order` totals for that same day within a 0% margin of error.
- **DI-02**: Monetary values MUST be consistent between `BigInt` centavos in the database and the formatted currency in the UI.

### 2. Dashboard Performance (DP)
- **DP-01**: All charts MUST render in less than 2 seconds for a standard date range (last 30 days).
- **DP-02**: Charts MUST be fully responsive on mobile (390px) and desktop (1440px) breakpoints.

### 3. Export Integrity (EI)
- **EI-01**: CSV export MUST contain all columns defined in the requirements (Date, OrderID, Provider, Amount, Fee, Status).
- **EI-02**: Large exports (>1000 rows) MUST NOT crash the server or exceed 128MB of heap memory usage during generation.

## UAT Scenarios

| ID | Scenario | Expected Result |
|----|----------|-----------------|
| UAT-01 | Create a new completed order | The "Real-time" GMV chart updates within 5 minutes. |
| UAT-02 | Filter dashboard by "Last 7 Days" | All charts reflect only data from the selected range. |

## Automation Requirements
- **Integration Test**: Verify that emitting an `OrderCompletedEvent` correctly updates the `DailyMetric` projection.
- **Unit Test**: Test the CSV streaming logic with mock data to ensure correct header mapping.
