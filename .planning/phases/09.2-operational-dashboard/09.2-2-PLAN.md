## Objective
Resolve the build failure (Issue #1 in UAT) caused by missing `swr` package and `shadcn` UI components in the `client` app.

## Proposed Changes

### apps/client
- `npm install swr` in the `client` workspace.
- Install required shadcn components: `button`, `dialog`, `input`, `label`.

## Execution
Run the following commands in the terminal:
```bash
cd apps/client
npm install swr
npx shadcn-ui@latest add button dialog input label --yes
```
