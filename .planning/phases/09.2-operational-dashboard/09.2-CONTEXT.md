# Phase 09.2: Operational Dashboard - Context

**Gathered:** 2026-07-14
**Status:** Ready for planning

<domain>
## Phase Boundary

Construir o painel administrativo aprimorado para monitoramento financeiro e de qualidade da plataforma (DASH-01, DASH-02, DASH-03).
</domain>

<decisions>
## Implementation Decisions

### Layout & Drill-down
- **D-01:** Implementar resumo de alto-nível (cards com totais) que redirecionam para uma lista granular e detalhada de transações ou avaliações.

### Data Freshness
- **D-02:** Utilizar `polling` periódico (ex: a cada 30-60 segundos) para atualizar os dados, evitando a complexidade desnecessária de WebSockets/SSE neste momento.

### Sensitive Operations (Bulk Payouts)
- **D-03:** Utilizar um modal de confirmação simples (ex: exigir que o admin digite 'CONFIRMAR') combinado com um log de auditoria no banco para rastrear qual admin acionou/parou os pagamentos, sem exigir 2FA ou senhas adicionais.

### Quality Visualization
- **D-04:** Exibir o estado atual (Snapshot) das métricas de qualidade com setas de tendência simples (indicando evolução vs. semana/período anterior) em vez de gráficos históricos complexos.
</decisions>
