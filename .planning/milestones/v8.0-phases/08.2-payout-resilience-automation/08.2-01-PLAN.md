    2. Implementar o método `findByExternalId(externalId: string): Promise<PayoutProps | null>` na classe `PrismaPayoutRepository`.
       A implementação deve buscar no banco de dados o registro único usando o campo `externalId` e usar o método privado `this.toProps(raw)` para mapear a resposta.
       
       ```typescript
       async findByExternalId(externalId: string): Promise<PayoutProps | null> {
         const raw = await this.prisma.payout.findUnique({
           where: { externalId },
         });
         if (!raw) return null;
         return this.toProps(raw);
       }
       ```
