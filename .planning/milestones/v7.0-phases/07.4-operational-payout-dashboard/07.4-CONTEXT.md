<decisions>
## Implementation Decisions

### Localização e Navegação
- **D-01:** Criar uma página dedicada em `/admin/payouts` na aplicação frontend (Next.js App Router). Não misturar com a home do painel para evitar poluição visual e permitir filtros avançados.

### Estrutura da Interface
- **D-02:** A interface utilizará uma visão por abas (Tabs). A aba principal "Aguardando Aprovação" focará apenas nos payouts com status `PENDING_APPROVAL` para ação rápida. Uma segunda aba "Histórico" servirá como consulta geral.

### Detalhamento da Informação
- **D-03:** A visualização de detalhes mostrará o nome do prestador, valor bruto, deduções de taxas, status atual e os dados bancários mascarados. 

### Segurança e Controle de Acesso
- **D-04:** A proteção das rotas e botões será baseada na sessão JWT existente verificando a `UserRole.ADMIN`. Não será exigida re-autenticação (MFA ou senha secundária) no momento de aprovar ou bloquear. O log de auditoria registrará o ID do Admin.

### the agent's Discretion
- Design dos componentes visuais (aproveitando o padrão "Emerald" já usado no `/admin/page.tsx`).
- Nomenclatura exata dos endpoints da API, desde que fiquem sob `/admin/payouts`.

</decisions>

## Existing Code Insights

### Reusable Assets
- `apps/client/src/app/admin/page.tsx`: Contains the styling baseline (Tailwind `bg-slate-950`, `text-emerald-400`, `lucide-react` icons, glassmorphism cards) and table structure that should be reused for the Payouts list.
- `FinancialAuditService`: Existing service in `shared-kernel` to be injected in the new `AdminPayoutController` for logging overrides.

### Established Patterns
- Payout Statuses: Uses `PayoutStatus` enum (`PENDING_APPROVAL`, `SCHEDULED`, `PROCESSING`, `PAID`, `FAILED`, `CANCELLED`).
- Security: Existing `JwtAuthGuard` and Roles/Permissions setup for API protection.

### Integration Points
- Backend: A new `AdminPayoutController` (or similar) will sit in `apps/api/src/modules/payments/interface/http/` to expose payout management.
- Frontend: New route at `apps/client/src/app/admin/payouts/page.tsx`.

</code_context>
