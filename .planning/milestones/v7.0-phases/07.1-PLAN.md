# Plan — Phase 7.1: Payout Automation & Ledger Hardening

## Overview
This phase implements the automated payout lifecycle. We will add the necessary database models, implement the `PayoutService` with batch processing, and secure bank account management in the Provider App.

<task read_first="apps/api/src/modules/payments/application" acceptance_criteria="ProcessDailyPayoutsUseCase scans all wallets with balance > 0 and creates Payout records.">
<action>
1. Create `ProcessDailyPayoutsUseCase` in `apps/api/src/modules/payments/application/process-daily-payouts.usecase.ts`:
    - Fetch all `Wallet` where `balance > 0`.
    - Check if `ProviderProfile.bankDataUpdatedAt` is < 24h ago; if so, skip (Change Lock).
    - For each: 
        - Check `amount > 200000` (R$ 2.000,00 in cents).
        - If high value: Create `Payout` with `PENDING_APPROVAL`.
        - Else: Create `Payout` with `PROCESSING`.
</action>
</task>

<task read_first="apps/api/src/modules/payments/infrastructure/queues" acceptance_criteria="ExecutePayoutProcessor calls Pagar.me and updates Payout/Wallet status.">
<action>
1. Create `ExecutePayoutProcessor` (BullMQ) to handle `execute-bank-transfer` jobs.
2. Logic:
    - Call `payoutAdapter.transfer()`.
    - On success: Update `Payout` to `PAID`.
    - On failure: Update `Payout` to `FAILED` and trigger **Reversal**.
</action>
</task>

## Must Haves (Goal-Backward Verification)
- [ ] O `PayoutService` deve subtrair o saldo da Wallet **antes** de tentar a transferência (Pre-debit pattern).
- [ ] O `Payout` deve registrar o `fee` retornado pelo gateway para conciliação.
- [ ] Alterações de dados bancários devem bloquear Payouts por 24h automaticamente.

## Threat Model
| Threat | Impact | Mitigation |
| :--- | :--- | :--- |
| Double Payout | High | Idempotency key based on `payoutId` + `WalletTransaction.externalId`. |
| Bank Data Tampering | High | Encryption (AES-256) + Audit log of changes + Threshold approval. |
| Negative Wallet Balance | High | Atomic Prisma transactions for `registerPayout`. |
