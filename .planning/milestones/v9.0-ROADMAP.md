# Roadmap — Milestone v9.0: Operational Dashboard

## Phase 09.1: Granular Feedback Loops
**Goal**: Implement customer and provider feedback loops with evidence verification and background tiering calculations.
- **Requirements**: FDBK-01, FDBK-02, FDBK-03.
- **Success Criteria**:
    - Customers can review services with thumbs up/down, mandatory photo verification, and select reasons tags.
    - Providers can review customers and provide completion proof.
    - Provider rating and tier is updated asynchronously via BullMQ on queue events.

## Phase 09.2: Operational Dashboard
**Goal**: Build the administrative control center for platform financial and quality metrics.
- **Requirements**: DASH-01, DASH-02, DASH-03.
- **Success Criteria**:
    - Admin can view real-time charts and metrics for payments, disputes, and ratings.
    - Admin can manually pause/resume bulk payouts.
    - Reused shadcn/ui components are fully functional.
