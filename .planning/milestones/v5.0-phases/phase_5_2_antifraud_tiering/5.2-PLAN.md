# Plan — Phase 5.2: Anti-fraud & Tiering Engine

## Objective
Implement a multi-layered trust system including physical geofencing (PostGIS), velocity-based fraud detection (EventEmitter2), and a performance-based tiering engine (BullMQ), managed via a secured Backoffice dashboard.

## Threat Model
<threat_model>
- **GPS Spoofing / Proxy Check-in**: Providers bypass frontend restrictions. (Mitigation: Mandatory Backend ST_Distance validation during check-in).
- **Volume Farming**: Providers create fake orders to boost metrics. (Mitigation: Async velocity check capping at 20 services/24h).
- **Unauthorized Data Access**: Users accessing admin endpoints. (Mitigation: Identity-level RolesGuard with ADMIN role).
- **Tier Manipulation**: Fraudulent metrics triggering upgrades. (Mitigation: Daily async job that verifies fraud status before upgrading).
</threat_model>
