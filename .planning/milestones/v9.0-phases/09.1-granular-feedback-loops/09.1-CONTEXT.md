</domain>

<decisions>
## Implementation Decisions

### Estrutura do Feedback
- **D-01:** Utilizar sistema de Thumbs up/down.
- **D-02:** Em caso de avaliação negativa (Thumbs down), exigir obrigatoriamente a seleção de Tags de motivos pré-definidas.

### Coleta de Evidências
- **D-03:** Obrigatoriedade dupla: tanto o Prestador quanto o Cliente devem anexar evidências fotográficas ao final do serviço para embasar o feedback.

### Motor de Cálculo de Tier
- **D-04:** Recálculo assíncrono: emitir um evento para o BullMQ após a submissão de feedback, delegando a atualização do Tier para uma fila em background (visando performance e escalabilidade).

</decisions>
