# Discussion Log — 06.3: Mobile Production & Publishing

## Summary
The implementation discussion focused on balancing production readiness with pragmatic development speed. Key decisions were made to prioritize data privacy (LGPD) for KYC and simplicity for offline storage.

## Participants
- **User** (Visionary)
- **Antigravity** (Builder)

## Areas Discussed

### 1. Identity & Security (KYC)
- **Options**: Public URLs vs Pre-signed URLs.
- **Decision**: Pre-signed URLs (Private).
- **Rationale**: Ensure compliance with data privacy regulations for sensitive documents.

### 2. Infrastructure (EAS Build)
- **Options**: Dedicated Staging vs Production-pointing Preview.
- **Decision**: Production-pointing Preview.
- **Rationale**: Faster validation cycle for internal testing without additional infra overhead.

### 3. Storage (Offline)
- **Options**: AsyncStorage vs MMKV/SQLite.
- **Decision**: AsyncStorage.
- **Rationale**: Sufficient for the "Offline Lite" scope while maintaining maximum compatibility and simplicity.

### 4. Notifications
- **Options**: Client-only infra vs Backend Service.
- **Decision**: Full Backend Integration (`NotificationService`).
- **Rationale**: Required to meet the success criteria of automated push delivery.

## Deferred Items
- Automated KYC providers.
- Advanced Liveness detection.
- Offline Write-Sync queues.
