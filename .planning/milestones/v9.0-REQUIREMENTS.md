# Requirements — Milestone v9.0: Operational Dashboard

## 1. Operational Dashboard
- [x] **DASH-01**: Admin can view a consolidated dashboard of financial metrics (payouts, chargebacks).
- [x] **DASH-02**: Admin can view service quality metrics (provider ratings, dispute ratios).
- [x] **DASH-03**: Admin can manually trigger or halt bulk payouts from the dashboard.

## 2. Granular Feedback Loops
- [x] **FDBK-01**: Customer can submit detailed evidence-based feedback after service completion.
- [x] **FDBK-02**: Provider can submit evidence of service completion and feedback on the customer.
- [x] **FDBK-03**: System calculates dynamic provider tier based on new feedback metrics.

## Future Requirements (Backlog)
- Advanced AI analysis for evidence photos.

## Out of Scope
- Provider matchmaking based on feedback (already exists, we are just updating the scoring metrics).
